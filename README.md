# Sachin Portfolio — Static HTML/CSS/JavaScript

No React, Next.js, npm, build tools, or backend are required.

## Files
- `index.html` — complete portfolio
- `project.html` — reusable project case-study page
- `css/style.css` — all layout, responsive styling, and animations
- `js/script.js` — navigation, scroll reveals, parallax, custom cursor, and contact form
- `js/project.js` — project case-study data
- `images/` — all portfolio images

## Run
Open `index.html` directly, or use a local server for the best result:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
